## 首页浏览器联调

Edge 无头浏览器访问 `http://127.0.0.1:5173/`，加载真实 GLB 和 Three.js 场景。测试在浏览器初始化时注入模拟语音转写及播报，模型通过本地 Worker 请求真实 `qwen3.8-omni-flash`。

1. 未唤醒时说「打开左前车窗」，车窗不动作，也不请求模型。
2. 说「小满小满，打开左前车窗」，真实车窗降下，部件面板同步，无模型请求。
3. 手动升窗后说「小满小满，车里有点闷热」，真实模型生成开窗建议；确认前车窗保持升起。
4. 点击「需要」后真实车窗降下，执行回执再次送给模型，最终显示完成 1 项、失败 0 项。此轮共 2 次真实模型请求。
5. 规则执行「关闭所有车窗，熄火」，不增加模型请求；关闭语音后状态正确。全过程无未捕获页面异常。

此前工具闭环还通过真实千问与模拟执行器验证三项中一项失败的情况：仅后备箱重试，三个执行器调用次数为 1、1、2。详见 [接口验证记录](../server/VERIFICATION.md)。

## 车辆回归

使用首页作为验证入口：

```powershell
$env:PREVIEW_URL = 'http://127.0.0.1:5173/'
$env:SOFTWARE_WEBGL = '0'
node dev/vehicle-interaction/browser-check.mjs
```

Chrome 无头默认图形后端下全部通过：十部件独立开合、双向轻点、长按慢移、按钮外松手、中途反向、雨刮归位、开门后窗热点、批量门窗、空白点击和拖拽保护、滚轮缩放、复位、直接拾取与后视角。无未捕获异常。

本次软件 WebGL 下十部件开合通过，但长按移动比例的计时断言失败；同一脚本使用默认图形后端完整通过。真实演示设备上的流畅度仍需实际观察。
