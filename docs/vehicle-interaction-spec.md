## 1. 分支交付

- **场景**。加载固定版本的 FormDrive 2018 Tesla Model 3，采用白色展厅、银色清漆材质、柔光箱环境反射、主光和落地阴影。地面显示柔化、渐隐的实时倒影。拖拽旋转、滚轮缩放，并提供重置视角。加载时展示等待状态，失败时提供重试。
- **部件**。四门、四窗、前后备箱共十个部件各自开合。车窗沿车门滑动，进入门板的玻璃通过随车门变化的裁切平面隐藏，保持玻璃透明度稳定。车门打开时窗仍可升降。关闭动作回到资产的初始姿态。雨刮支持独立启动、双臂循环摆动和关闭后归位。
- **点击**。区分轻点和拖拽，取车模最近可见表面，忽略静态车身和空白。车身上可见的热点随视角和部件更新。窗玻璃完全降下后，仍可点窗框热点升回。
- **界面**。全屏无外框展厅叠加白色半透明小窗。车门、车窗和备箱分组，四门和四窗各按方位排成 2×2。每个车窗有独立的“升起 / 降下”按钮，支持轻点自动到位和长按连续慢移。停止后显示实际降下百分比，支持全车门和全车窗动作。场景点击与面板点击走同一个控制器。
- **控制器**。实现已有的 `VehicleController` 契约，包括模拟引擎、稳定快照、同部件串行、按顺序执行语音批次和撤销未下发动作。开发验证页提供可独立验收的入口。语音、模型服务和生产入口装配分别由其功能分支和联调分支负责。

## 2. 接口与文件边界

| 产物 | 约定 |
| --- | --- |
| `src/scene/Showroom.tsx` | 导出 `Showroom`，遵守 `ShowroomProps`。模型节点绑定完成后报告驱动，卸载时解除绑定。拾取和热点均上报业务 `PartId`。 |
| `src/scene/model3Parts.ts` | 保存已锁定资产的节点名称、局部转轴与滑动参数。节点唯一匹配后才开始接收部件动作。 |
| `src/vehicle/vehicleController.ts` | 导出 `createVehicleController()`。稳定状态由驱动到位回执提交，失败与取消各有结果。驱动更换时废弃旧回执，部件同步到新模型的闭合初始状态。 |
| `src/ui/PartPanel.tsx` | 消费控制器快照，通过同一控制器发出单部件和组动作。门与备箱运动中禁用重复点击，车窗允许中途反向操作。提供独立雨刮开关。 |
| `src/ui/WindowButton.tsx` | 管理双向轻点、长按、指针捕获、键盘及失焦取消，通过控制器执行和停止运动。 |
| `src/scene/StudioEnvironment.tsx`、`ReflectiveFloor.tsx` | 提供白色展厅光照、环境反射、地面倒影及资源清理。 |
| `src/scene/wipers.ts` | 绑定资产中两根雨刮的独立转轴，控制循环和归位。 |
| `public/models/` | 保存原始 GLB 和模型许可说明，移植的源码注明上游 MIT 许可。 |
| `dev/vehicle-interaction/` | 装配场景、控制器和控车小窗，供本地体验与浏览器验收。 |

左右按车辆前进方向定义。门和箱盖转动采用上游局部轴与角度。玻璃保持车门子节点关系，下降行程按玻璃高度和上游参数确定。对同一个目标重复下达语音动作时，控制器返回已到目标；组内并行，整组到位后继续下一条动作。独立部件可同时执行。

### 车窗操作约定

| 操作 | 行为 |
| --- | --- |
| 轻点“降下” | 自动降到底；轻点“升起”自动升到顶。 |
| 按住任一方向超过 280 ms | 切换到该方向的连续慢移，起步平缓，全行程约 2.3 秒。 |
| 长按后松开 | 停在实际位置；拖出按钮再松开也停止。失焦、指针取消或组件卸载同样停止。 |
| 自动运动中轻点反方向 | 从当前位置平滑反向，自动运行到另一端。 |
| 停在中间后轻点任一方向 | 从实际位置继续自动运行到对应端点。 |
| Space / Enter | 与鼠标一致，短按自动到位，长按连续慢移，松开停止。 |

取消“半降”预设。轻点自动运动采用平滑起止曲线，全行程约 1.15 秒；长按手动运动单独使用慢速曲线。动画在渲染循环内按时间更新，不依赖 React 逐帧重渲染。

### 增量契约

保留 `VehicleAction` 的 `part`、`group`、`engine` 三种类型。窗口动作可选 `openness`，范围为 0（完全升起）到 1（完全降下），`open` 与是否大于 0 保持一致；非车窗及越界值返回 `failed`。快照可选记录 `openness` 和 `targetOpenness`，稳定位置以场景实际回执为准。

场景驱动可选扩展 `setWindowOpenness(id, value, { manual })`、`getWindowOpenness(id)`、`stopWindowMovement(id)` 和 `setWipersRunning(running)`。控制器可选扩展 `beginWindowMove(id, 'raise' | 'lower')`、`stopWindow(id)` 和 `setWipersRunning(running)`，快照通过能力标记决定 UI 是否启用高级操作。原有仅支持全开全关的驱动仍可使用。

手动释放会取消尚未启动的同次手势，避免松手后队列继续升降。雨刮状态为 `off / running / parking`，归位期间禁用开关，其他部件可照常操作。本分支提供点击入口和控制接口，新增语音意图接线属于语音分支。

## 3. 独立验收

| 编号 | 操作 | 预期 |
| --- | --- | --- |
| V01 | 打开验证页，拖拽和滚轮，重置视角 | 模型完整呈现，操作跟手，重置回到初始构图。拖拽松手和点击空白无部件动作。 |
| V02 | 从面板逐一打开并关闭十个部件 | 目标部件动画到位，其他部件保持各自状态，小窗同步反馈。 |
| V03 | 打开左前门并降下左前窗，再从窗框热点升起 | 门保持开启，窗玻璃随门并可独立升降。 |
| V04 | 点击可见门板、玻璃和箱盖，再操作全车门、全车窗 | 画面和小窗一致，批量动作覆盖对应四个部件。 |
| V05 | 使用模拟场景驱动测试队列、取消、失败、换场景和引擎状态 | 快照和结果与契约一致，旧驱动的回执不会覆盖新场景。 |
| V06 | 构建项目并验证子路径资源 | TypeScript 和 Vite 构建通过，模型资源可随 GitHub Pages 子路径加载。 |
| V07 | 分别轻点车窗的升起、降下按钮 | 两个方向均自动到达端点，中间位置也可继续到位。 |
| V08 | 分别长按升起和降下，再松开、拖出按钮松开 | 两个方向均缓慢连续移动，松开后保留任意位置，无延迟启动。 |
| V09 | 自动降窗途中轻点升起 | 玻璃从当前位置反向升到顶，位置与小窗一致。 |
| V10 | 启动雨刮并操作车窗，再关闭雨刮 | 双臂循环摆动，独立于车窗，关闭后完成当前周期回到初始位置。 |
| V11 | 观察白色展厅并拖动视角、开合部件 | 车漆有柔光反射、地面有随车身和视角变化的倒影，保持已完成的 BVH 拾取优化。 |

V01–V04 对应需求 A02–A03。V05 支撑 A04、A07、A08 和 A11 的动作执行。正式页面及语音流程在联调阶段验收。
